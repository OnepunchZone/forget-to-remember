# Forget to Remember
Приложение для напоминаний о ДР с кастомными поздравлениями, лайками и отправкой в мессенджеры.

## Фичи
- Авторизация (USER/ADMIN)
- Хранение ДР и шаблонов
- Лайки и сортировка по популярности
- Уведомления и отправка

## Запуск
mvn spring-boot:run
http://localhost:8080 - адрес веб
@Foreget_to_Remember_Bot - адрес тг бота
